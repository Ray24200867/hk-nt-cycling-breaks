# 【數據】在新界踩單車代步：路要接得上，車要有處泊

完整靜態網站，可使用 GitHub Pages 發布，無須建置或安裝套件。

## 上傳至 GitHub Pages

1. 解壓 ZIP，將全部網站檔案及資料夾上傳至儲存庫根目錄。`index.html`、`assets/`、`components/` 必須同層；不要只上傳 ZIP。
2. 在 **Settings → Pages** 選擇 **Deploy from a branch**。
3. 選擇已上傳檔案的分支（通常為 `main`）及 **/ (root)**，儲存並等待發布完成。

請保留 `.nojekyll` 及所有相對路徑。

```sh
python3 -m http.server 8765
```
